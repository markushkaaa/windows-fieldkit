# Third-party components

Windows executables bundle CPython, distributed under the [Python Software Foundation License](https://docs.python.org/3/license.html), and are built with [PyInstaller](https://pyinstaller.org/en/stable/license.html). The OBS tools use [websocket-client](https://github.com/websocket-client/websocket-client/blob/master/LICENSE) under Apache License 2.0. FFmpeg is a separate user-installed tool and is not bundled.
